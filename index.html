외부 화물 플랫폼의 오더를 AtlanTruck 안에서 받아 배차까지 이어지도록 앱 간 연동 인터페이스를 직접 설계 — 이 인터페이스가 6개사 연동 개발의 기준이 됐다. 개발자가 곧 창구가 되어 각 사와 직접 커뮤니케이션하며 스펙 협의부터 연동 개발, 이슈 대응까지 전 과정을 주도. 대기업 물류 계열(LG·CJ·현대)부터 업계 상위 주선 플랫폼까지 6개사의 오더를 끌어오며 회사의 신사업 확장을 이끌었다.

BEFORE결제 기능이 없는 무료 앱 — 자체 매출 0원
AFTER유료 회원 1,500명의 구독 서비스 — 가입부터 해지까지 결제 전 과정을 0에서 구축

무료 앱에 구독 결제를 0에서 새로 구축해 유료 비즈니스 모델로 전환. 플레이스토어 인앱결제(수수료 15~30%) 대신 카드·계좌 자체 PG 직접결제를 구축해 매출 실수령을 극대화 — 인앱결제도 별도 구현·테스트까지 마쳐 두 결제 체계를 모두 경험. 첫 가입 한달 무료·해지 신청/취소·탈퇴 연계 분기 등 가입~해지 시나리오와 결제수단 CRUD(카드 등록/변경/삭제·대표수단 상태 판정), 출금동의 인증, 현금영수증(소득공제/지출증빙) 발행까지 결제 라이프사이클 전체를 담당. 가입~해지 단계별 GA 퍼널 로깅으로 이탈 구간 측정까지 설계.

광고 수익화 도입 미디에이션 연동 + SDK 안정화까지신규 0→1
BEFORE광고 지면도, 광고 수익도 없던 앱
AFTER매월 꾸준히 발생하는 광고 수익원 확보 — 광고사와의 협의 창구도 개발자가 직접 담당

광고 수익원을 0에서 도입. AdPopcorn·Adiscope 미디에이션(AdMob·TNK·Vungle·Pangle·Max 등)을 직접 연동하고, 보상형 광고(시청 제한·프리로드·보상 처리)·오퍼월·첫/종료화면 광고를 구축. 광고 업체와 직접 커뮤니케이션하며 연동 스펙 협의·이슈 대응·네트워크 추가/제거를 개발자가 창구가 되어 진행. 광고 네트워크 충돌 대응과 배너 프리로드 동시 로드 제한으로 광고 SDK발 OOM까지 직접 안정화, 배너별 GA 로그로 성과 측정.

AdPopcorn·Adiscope 미디에이션보상형·오퍼월업체 직접 커뮤니케이션OOM 방어광고 성과 GA 로그
다중경유지 배송순서 최적화 엑셀 업로드부터 배송 완료까지 클라이언트 파이프라인 전체신규 0→1
BEFORE수십 곳 배송지의 방문 순서를 기사가 경험과 감으로 직접 결정
AFTER엑셀 업로드 한 번이면 최적 방문 순서를 자동 산출 — 배송 완료까지 앱이 관리

다중 배송지의 방문 순서를 최적화하는 기능의 클라이언트 파이프라인 전체를 구축. 엑셀(XLSX/CSV) 대량 업로드 파싱 → 주소 정제 → 순서 최적화 연동 → 최적화된 배송 태스크의 상태 관리(운송중·완료)·드래그 순서 편집·재최적화 요청까지 담당. 배송 목록 공유, 최종 목적지 분기(출발지 복귀/차고지/마지막 배송지) 등 실사용 시나리오를 전용 UI 20여 화면으로 구현.

1t 전용경로 C++ 엔진 ↔ Kotlin, JNI 경계 직접 처리신규 0→1
BEFORE모든 화물차가 동일한 화물 경로를 안내받음
AFTER1t 화물차는 전용 경로를 일반 경로와 나란히 비교해 선택

1t 화물차 전용 경로를 일반 화물 경로와 함께 탐색·비교하는 기능. Kotlin UI와 C++ 경로 엔진 사이 JNI 경계를 직접 다루며 경로 옵션 슬롯 분기와 전용경로 결과 카드 구성을 구현. 특히 네이티브 워커 스레드에서 JVM으로 콜백하는 스레드 어태치 생명주기(GetEnv → AttachCurrentThread → DetachCurrentThread)를 깊이 분석·처리하며 네이티브-자바 간 통신 구조를 체득.

개발 기능 전체

오더 · 배차기존 서비스 확장

  • 목적지 주변 오더 — 배송 도착지 인근의 다음 일감을 지도 깃발로 표출해 연속 배차 유도
  • 묶음오더 — 혼적/연계/왕복 3종으로 여러 일감을 묶어 수익성 높은 배차 구성 (가로 스크롤 묶음카드 터치 충돌 제어·단가/운임순 소팅)
  • 오더추천 — 조건에 맞는 일감을 소켓 실시간 푸시(keepalive·재연결)와 FCM 풀스크린 알림으로 추천
  • 서류등록 · 배차내역 — 기사 서류 제출 플로우 개선, 결제·화주 정보가 담긴 배차 이력

길안내 · 내비게이션기존 서비스 확장

  • 1t 전용경로 — 일반 화물 경로와 1t 전용 경로 동시 탐색·비교 (상단 대표 작업)
  • 트럭 특화 안내 — 높이·중량·위험물 제한 도로 회피와 회피 이유·구간단속 안내
  • 도착예정알림 · 위치 공유 — 도착 예정 시간과 기사 위치를 상대방에게 공유
  • 유도선 색상 안내 — 교차로 진행 방향 유도선을 색상으로 직관화
  • 안전운전 안내 — 네트워크 DB 기반 안전운전 구간 안내
