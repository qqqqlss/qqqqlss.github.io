광고 수익화 도입 미디에이션 연동 + SDK 안정화까지신규 0→1

광고 수익원을 0에서 도입. AdPopcorn·Adiscope 미디에이션(AdMob·TNK·Vungle·Pangle·Max 등)을 직접 연동하고, 보상형 광고(시청 제한·프리로드·보상 처리)·오퍼월·첫/종료화면 광고를 구축. 광고 업체와 직접 커뮤니케이션하며 연동 스펙 협의·이슈 대응·네트워크 추가/제거를 개발자가 창구가 되어 진행. 광고 네트워크 충돌 대응과 배너 프리로드 동시 로드 제한으로 광고 SDK발 OOM까지 직접 안정화, 배너별 GA 로그로 성과 측정.

다중경유지 배송순서 최적화 엑셀 업로드부터 배송 완료까지 클라이언트 파이프라인 전체신규 0→1

다중 배송지의 방문 순서를 최적화하는 기능의 클라이언트 파이프라인 전체를 구축. 엑셀(XLSX/CSV) 대량 업로드 파싱 → 주소 정제 → 순서 최적화 연동 → 최적화된 배송 태스크의 상태 관리(운송중·완료)·드래그 순서 편집·재최적화 요청까지 담당. 배송 목록 공유, 최종 목적지 분기(출발지 복귀/차고지/마지막 배송지) 등 실사용 시나리오를 전용 UI 20여 화면으로 구현.

Apache POI·OpenCSV주소 정제태스크 상태 관리·재최적화ItemTouchHelper 드래그 편집
1t 전용경로 C++ 엔진 ↔ Kotlin, JNI 경계 직접 처리신규 0→1

1t 화물차 전용 경로를 일반 화물 경로와 함께 탐색·비교하는 기능. Kotlin UI와 C++ 경로 엔진 사이 JNI 경계를 직접 다루며 경로 옵션 슬롯 분기와 전용경로 결과 카드 구성을 구현. 특히 네이티브 워커 스레드에서 JVM으로 콜백하는 스레드 어태치 생명주기(GetEnv → AttachCurrentThread → DetachCurrentThread)를 깊이 분석·처리하며 네이티브-자바 간 통신 구조를 체득.
